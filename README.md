# 누구요 (nuguyo)

앱에서 직원 명부를 관리해 두면, 그 직원에게서 **전화나 문자가 올 때 통화 화면 위에
팝업**으로 누구인지 알려 주는 안드로이드 앱.

- 타깃 기기: **Galaxy S24 Ultra / Android 16 (API 36, One UI 8)**
- `minSdk 29`, `targetSdk 36`, Kotlin + Jetpack Compose + Room

전체 기술 검토와 단계별 계획은 [`docs/PLAN.md`](docs/PLAN.md) 에 있다.

## 빌드

Android Studio 로 열거나:

```bash
./gradlew assembleDebug        # APK
./gradlew testDebugUnitTest    # 번호 정규화·매칭 유닛테스트
```

`androidx` / AGP 산출물은 Google Maven(`dl.google.com`)에서 내려온다. 사내망에서
막혀 있으면 사내 미러를 `settings.gradle.kts` 의 저장소 목록에 추가해야 한다.

## 설치 후 반드시 해 줘야 하는 것

앱 첫 화면 우상단 방패 아이콘 → **동작 준비** 화면에서 아래를 모두 채운다.
하나라도 빠지면 "전화가 와도 아무 일도 일어나지 않는" 증상이 된다.

1. **다른 앱 위에 표시** — 팝업을 그릴 창을 얻기 위한 필수 권한
2. **발신자 표시 및 스팸 앱** (`ROLE_CALL_SCREENING`) — 걸려온 번호를 알아내는
   유일한 정식 경로. **기기당 한 앱만** 가질 수 있어 삼성 스팸차단·T전화·후스콜과
   동시에 쓸 수 없다
3. 전화 상태 읽기 — 통화를 받거나 끊을 때 팝업을 닫기 위해
4. 문자 수신 — 문자 팝업을 쓸 경우
5. 알림 — 팝업을 못 띄웠을 때의 폴백 통보
6. **배터리 사용량 "제한 없음"** — 삼성 절전이 앱을 재우면 팝업이 뜨지 않는다

Android 13+ 는 오래 안 쓴 앱의 권한을 자동 회수한다. 같은 화면 맨 아래
"앱 정보 열기"에서 자동 회수를 꺼 두는 게 좋다.

## 왜 이렇게 만들었나

기록해 둘 만한 설계 판단들:

- **`CallScreeningService`** — Android 10 부터 `PHONE_STATE` 브로드캐스트에 발신번호가
  실리지 않는다. `READ_CALL_LOG` 없이 번호를 아는 정식 경로는 이것뿐이다.
- **액티비티가 아니라 오버레이 창** — Android 12+ 백그라운드 액티비티 실행 제한과
  Android 14+ 풀스크린 인텐트 제한 때문에 통화 화면 위에 뭔가를 그릴 수단은
  `TYPE_APPLICATION_OVERLAY` 뿐이다.
- **FGS 타입 `specialUse`** — `phoneCall` 타입은 기본 전화앱이거나 `MANAGE_OWN_CALLS`
  를 가진 앱만 쓸 수 있다.
- **번호 정규화를 직접 구현** — 국내 번호만 다루므로 libphonenumber 메타데이터를
  넣을 이유가 없고, 사내 내선·안심번호처럼 libphonenumber 가 invalid 로 떨구는
  입력도 살려서 매칭해야 한다.
- **뒤 8자리 매칭은 후보가 유일할 때만** — `010-1234-5678` 과 `02-1234-5678` 은
  뒤 8자리가 같다. 애매하면 팝업을 안 띄우는 쪽이 낫다.
- **메모리 캐시 없음** — 색인된 컬럼 조회 두 번이면 끝나고, 명부를 수정했는데
  옛 이름이 뜨는 버그가 훨씬 아프다.
- **Hilt 대신 손조립** — 시스템이 직접 인스턴스화하는 컴포넌트마다 EntryPoint 를
  붙이는 비용이 그래프 크기에 비해 크다.

## 남은 위험

**One UI 통화 화면이 오버레이를 가릴 가능성.** 트루콜러류가 삼성에서 동작하니
될 확률이 높지만, 실기기 검증 전까지는 미확인이다. 실패하면 기본 전화앱
(`InCallService`)이 되어 통화 화면을 직접 그리는 방향으로 선회해야 한다
(`docs/PLAN.md` 의 "대안 B").

실기기 확인 순서:

1. **동작 준비** 화면에서 "테스트 팝업 띄우기" → 오버레이 자체가 뜨는지
2. 직원 한 명 등록 → 다른 전화기로 전화 → 벨 울릴 때 팝업이 통화 화면 위에 뜨는지
3. 문자 발송 → 팝업이 뜨고 설정한 시간 뒤 사라지는지
4. 화면을 끄고 잠금 상태에서 전화 → 팝업이 뜨는지
5. 앱을 강제 종료한 뒤 전화 → 콜드 스타트에서도 뜨는지
